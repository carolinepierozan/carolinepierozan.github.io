# carolinepierozan.github.io — portfolio

Personal portfolio for Caroline Pierozan, Product Designer & UX Researcher. Static HTML/CSS/JS, with soft pastel pink, lavender and baby-blue colors.

## Publish on GitHub Pages

Repository to create: **`carolinepierozan.github.io`**, under GitHub account `carolinepierozan` (public repository).

1. Create a new repository at <https://github.com/new> with repository name `carolinepierozan.github.io`. Leave **Add a README file** unchecked, because this package already contains one.
2. Upload **all files inside this folder** to the repository root (not the ZIP itself, and not a nested folder). In the new repository, use **Add file > Upload files**, drag the extracted files into the upload page, then commit changes to `main`.
3. Under **Settings > Pages > Build and deployment**, choose **Deploy from a branch**, branch **`main`**, folder **`/(root)`**. Save.
4. After GitHub finishes publishing, visit <https://carolinepierozan.github.io/>.

The `.nojekyll` file bypasses Jekyll handling, ensuring static files are published as-is. No build step or dependencies required. `index.html`, `styles.css`, `script.js`, `content.js`, and `favicon.svg` all belong at the repository root.

## Local preview

Open `index.html` in a browser or run `python -m http.server 8000` inside this folder to preview at `http://localhost:8000`.
